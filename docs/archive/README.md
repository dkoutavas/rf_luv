# Archived leap-era material

Runbooks and scripts written for `leap` (192.168.2.10, openSUSE Leap 15.6, user
`dio_nysis`), the host that ran the pipelines until its disk failed in June
2026. Kept for history. None of it applies to the current host as written.

- `ACARS-DEPLOY-LEAP-20260502.md`: the ACARS V4 takeover runbook over ssh.
  Current path: `acars/README.md`.
- `remote-desktop-leap/`: xrdp and Tailscale scripts that configure leap over
  ssh.
- `MORNING-CHECK-20260503.md`: a morning check from the ACARS soak.
